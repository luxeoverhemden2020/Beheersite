Website en koppeling

Eigen Shopify-app

  1. dev.shopify.com → Apps → Create app → Start from Dev Dashboard. Naam: Sitehulpje – klantnaam.
  2. App-URL: , insluiten uit.
    Omleidings-URL:
    Scopes:
  3. Uitbrengen, daarna Distribution → Custom → het adres hieronder.
  4. Kopieer Client ID en Client secret naar hieronder en klik op Opslaan en mailen.

>_WordPress / WooCommerce koppelen

  1. Sla de klant eerst op (code en website ingevuld).
  2. Download het koppelstuk voor deze klant.
  3. In WordPress: Plugins → Nieuwe plugin → Plugin uploaden → zip kiezen → Nu installeren → Activeren.
  4. Klik op Koppeling testen.

Met de API-sleutel werkt de snelle webbeheerder dan meteen. De deurbel hierboven is alleen nodig als achtervang voor hele grote klussen.
